[보장비교분석 · 웹서버 올리기 / 폰 설치 안내]   (Netlify · GitHub Pages 어느 쪽에도 같은 파일을 올립니다)

■ 올릴 파일 (모두 같은 폴더에, 폴더째 그대로)
   index.html / manifest.webmanifest / sw.js / 404.html / .nojekyll / icons 폴더
   ※ 「보장비교분석_모바일.html」은 올리지 않아도 됩니다(index.html 과 내용이 같습니다).
   ※ .nojekyll 은 이름이 점(.)으로 시작하는 빈 파일입니다. 탐색기에서 안 보이면 「숨김 항목」을 켜세요.

■ A. Netlify (기존 방식)
   1) Netlify 사이트의 「Deploys」 화면에 이 폴더를 통째로 끌어다 놓습니다.
   2) 주소 예: https://○○○.netlify.app/

■ B. GitHub Pages (https://wonsr72.github.io/Insurance-Comparison/)
   1) GitHub 저장소 Insurance-Comparison 의 맨 위(루트)에 위 파일들을 올립니다. (Add file → Upload files → 폴더째 끌어놓기 → Commit)
      - index.html 은 반드시 저장소 맨 위에 있어야 합니다(폴더 안에 넣으면 주소가 달라집니다).
   2) Settings → Pages → Branch 를 main(또는 master) / (root) 로 지정 → Save.
   3) 1~2분 뒤 https://wonsr72.github.io/Insurance-Comparison/ 에서 열립니다.
   4) 새 버전: 같은 파일을 덮어써서 올리면 됩니다(폰은 다음에 열 때 자동으로 새 버전을 받습니다).
   ※ 파일 하나가 100MB 를 넘으면 안 되는데 현재 약 8MB 라 괜찮습니다.

■ 폰 설치 (두 곳 공통)
   주소가 https:// 로 시작해야 합니다. 폰에서 열면 로그인 화면에 「📲 폰에 설치하기」 단추가 보입니다.
   - 안드로이드(크롬): 단추 → 설치.   - 아이폰: 사파리로 열고 단추 → 공유(□↑) → 홈 화면에 추가.

■ 알아 둘 점
   · 두 주소는 서로 다른 사이트라서 브라우저에 저장된 설정(로그인 상태·폴더 연결 등)이 따로입니다.
     고객 자료는 구글시트로 공유되므로 어느 주소에서 열어도 같은 자료가 보입니다. 처음 한 번만 각 주소에서 구글시트 연결(연결 링크)을 해 주세요.
   · 「연동서버(/api 중계)」는 두 곳 모두 없는 기능이라, 필요한 기능은 PC판의 연동서버를 쓰세요.
